# 游戏内任务生成器与程序化任务系统

## 项目描述

游戏内任务生成器与程序化任务系统的bug修复项目。核心模块 `quest/generator.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 任务生成完全没做任务都是固定的
- 模板引擎完全没做不能组合生成新任务
- 任务构建完全没做不能从目标生成完整任务
- 动态难度完全没做任务难度永远一样
- 任务验证完全没做生成的任务可能无法完成

## 运行测试

```bash
python -m pytest tests/test_quest_generator.py -q
```

修复目标：所有 14 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
